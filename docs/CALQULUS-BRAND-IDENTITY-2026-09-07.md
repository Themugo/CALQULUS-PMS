# CALQULUS Brand Identity — 2026-09-07

## Direction
The existing product layout and information architecture remain unchanged. This initiative is a visual identity convergence: premium deep navy chrome, accessible CALQULUS blue interactions, cyan/teal energy, emerald growth accents, and soft tinted application surfaces.

## Canonical palette
- Deep Navy: `#0A2540` — header, sidebar, footer, premium chrome
- CALQULUS Blue: `#0074E6` — primary interactive actions and focus
- Cyan: `#06B6D4` — accent, tenant/platform identity and brand energy
- Emerald: `#10B981` — growth/success and landlord identity
- Lime: `#84CC16` — logo roof highlight / restrained decorative accent
- Surface: `#FFFFFF`
- Application background: `#F1F5F9`
- Soft tinted background: `#EAF2F8`
- Border: `#E2E8F0`
- Text: `#0F2942` / `#64748B`

## Logo system
The default CALQULUS mark is transparent and uses the C-orbit + property motif. The app icon retains a deep navy field so it remains legible on phone launchers. Organization/public-site logo overrides remain supported.

## Public-site configurability
The public header and footer continue to consume `config.brand.name`, `config.brand.descriptor`, and `config.brand.logoUrl`. No public-page logo override has been removed. The identity change only establishes the platform default visual language.

## Layout rule
No page structure, navigation architecture, information hierarchy, or portal workflow is redesigned by this initiative.
